Éléments

    Aucun élément. Créez-en un, ou importez le fichier de collecte dans l’onglet Publier.

    Nouvel élément

    Utilisez une photo dont vous détenez les droits ou sous licence libre, et indiquez le crédit. Elle est réduite à 1200 px de large.

    Aperçu dans le journal

    Rendu réel du journal, mis à jour pendant que vous écrivez. Rien n’est publié. Si la zone reste vide, publiez d’abord la dernière version du journal (index.html).

    Rédiger l’édition

    Le fil continu reste alimenté au fil de l’eau. L’édition regroupe, chaque semaine, l’essentiel et une analyse. Elle devient un article de la rubrique Analyses.

    Éléments validés à retenir

      Aucun élément validé pour l’instant.

      Connexion au journal

      Une fois la connexion enregistrée, la rédaction met le journal à jour toute seule : chaque validation, retrait ou suppression envoie le nouveau data/items.json dans le dépôt du journal. Le journal affiche le changement 1 à 2 minutes plus tard. Seuls les éléments validés sont envoyés, avec leurs photos (dossier images/ du dépôt).

      Le jeton reste dans ce navigateur, jamais dans le dépôt. Créez-le sur GitHub : Settings, Developer settings, Personal access tokens, Fine-grained tokens. Accès au seul dépôt du journal, permission « Contents : Read and write ».

      Publication manuelle (secours)

      Les photos ne sont envoyées que par la connexion automatique.

      1. Copiez le contenu ci-dessous.
      2. Dans votre dépôt GitHub, remplacez le contenu du fichier data/items.json.
      3. Le journal affiche les éléments « validés » au prochain chargement.

      Importer

      Collez le contenu de data/items.json (par exemple après une collecte automatique) pour valider ou corriger les éléments. Les éléments déjà présents ne sont pas écrasés.

      Les éléments sont enregistrés dans ce navigateur seulement. Copiez et publiez régulièrement.
