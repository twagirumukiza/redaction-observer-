            Importer un article

            Comment préparer le document ?
            • Titre : en style « Titre » dans Word, ou en # Titre en Markdown.
            • Lignes d’en-tête (facultatif) : Rubrique :, Étiquette :, Auteur :, Date :, Source :, URL :.
            • Intertitres reconnus : Introduction, L’information, L’analyse, Actions (liste à puces), Conclusion, Pour aller plus loin.
            • Autres intertitres : ils deviennent des parties supplémentaires de l’article.
            • Mise en forme conservée : gras, italique, liens, listes, tableaux et images.
            • Images : la première devient la photo de l’article. Les suivantes sont ajoutées à l’analyse, 6 au maximum.
            • PDF : texte seulement, à relire attentivement.

            Rédigez votre article dans Word (.docx), en Markdown (.md) ou en texte, ou partez d’un PDF. Le fichier est converti, puis ouvert dans le formulaire pour que vous le vérifiiez avant de le publier. Rien n’est publié automatiquement.

            Importer un lexique

            Chargez un document (Word .docx, PDF, .txt ou .md) qui contient plusieurs termes. Ils sont détectés, présentés dans une liste que vous pouvez corriger, puis ajoutés à la rubrique Lexique. Reconnus : « Terme : définition », « Terme – définition », « SIGLE (Forme développée) : définition », un tableau Terme | Définition, ou un intertitre suivi de sa définition. Rien n’est publié automatiquement.

                            Connexion au journal

                            Une fois la connexion enregistrée, la rédaction met le journal à jour toute seule : chaque validation, retrait ou suppression envoie le nouveau data/items.json dans le dépôt du journal. Le journal affiche le changement 1 à 2 minutes plus tard. Seuls les éléments validés sont envoyés, avec leurs photos (dossier images/ du dépôt).

                            Le jeton reste dans ce navigateur, jamais dans le dépôt. Créez-le sur GitHub : Settings, Developer settings, Personal access tokens, Fine-grained tokens. Accès au seul dépôt du journal, permission « Contents : Read and write ».
